# WA Direct Chat

Aplikasi web ringan untuk membuka obrolan WhatsApp tanpa perlu menyimpan nomor ke kontak HP, dilengkapi pembersih format nomor otomatis, template pesan cepat, dan riwayat nomor terakhir.

## Fitur Utama

- **Auto-Format Nomor:** Otomatis membersihkan spasi, tanda strip, serta mengubah awalan `0` atau `8` menjadi kode negara (`62`).
- **Tempel Instan:** Ambil nomor langsung dari clipboard dengan satu klik.
- **Template Chat Cepat:** Simpan dan pakai ulang format pesan yang sering dipakai (kurir paket, patokan alamat, tanya stok).
- **Riwayat Lokal:** Menyimpan 8 nomor terakhir langsung di `localStorage` browser tanpa mengirim data ke server mana pun.
- **Mode Gelap Otomatis:** Menyesuaikan tampilan terang atau gelap mengikuti pengaturan perangkat.
